# 0070: Resizable sidebars

## Description

The sidebars of the web UI — the left documents sidebar and the right AI chat
panel — should be resizable by the user.

## Acceptance criteria

- [ ] The left sidebar can be resized by dragging its edge.
- [ ] The right AI chat can be resized by dragging its edge.

## Tests

- Frontend regression tests for the resizable sidebar widths.

## Notes

- Follow-up to tickets 0067–0069: the sidebar items became collapsible and
  nested, and the panels now also need a manual width.
